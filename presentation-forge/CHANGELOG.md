# Changelog

All notable changes to presentation-forge are documented here.

## [1.1.0] - 2026-01-13

### Security Fixes (P0)
- **URL Injection Prevention**: `slide-crawler.js` now validates URLs against host allowlist (`localhost`, `127.0.0.1`, `0.0.0.0`). External URLs are blocked.
- **Slide Count Validation**: New `validate-slide-count.js` utility catches YAML-to-markdown slide drift during generation.

### Improvements (P1)
- **Server Availability Check**: Validators now explicitly check if Slidev server is running before starting. Clear error message with guidance if unavailable.
- **Resource Limits**: Added `MAX_SLIDES=200` and `OPERATION_TIMEOUT_MS=120000` to prevent runaway crawls.
- **Static Validation Mode**: New `validate-static.js` enables markdown-only validation without Slidev server. CI/CD compatible.

### New Templates (P2)
- **hybrid-stakeholder-technical**: Multi-stakeholder template with:
  - Part 1: Executive Overview (leadership decisions)
  - Part 2: Technical Deep Dive (engineering details)
  - Part 3: Operations (DevOps/SRE concerns)
  - Audience-switching markers for presenter guidance

### Dependencies Added
- `js-yaml@^4.1.0` - Required for slide count validation
- `node-fetch@^3.3.0` - Required for server availability check

### Validation Test

- Static validation passed
