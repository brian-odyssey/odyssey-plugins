# Resmark Claude Code Plugins

Private plugin marketplace for Resmark.

## Installation

```bash
# Add marketplace (one-time)
/plugin marketplace add resmark/claude-plugins

# Install plugins
/plugin install verbalized-sampling@resmark
```

## Available Plugins

| Plugin | Description |
|--------|-------------|
| `verbalized-sampling` | Enhance LLM diversity with probability-weighted option generation |

## Access

This is a private marketplace. Contact your admin for access.
